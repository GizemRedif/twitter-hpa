# Data Klasörü

Bu klasör, projenin ham veri setini barındırır.

## Tweets.csv Dosyası

Projeyi yerelinizde veya bulutta çalıştırmak için gerekli olan orijinal veri setine (`Tweets.csv`) bu dizinden ulaşabilirsiniz.

### Veri Seti Detayları
* **Kaynak:** [Kaggle - Twitter US Airline Sentiment](https://www.kaggle.com/datasets/crowdflower/twitter-airline-sentiment)
* **Kullanım:**
  * **Yerel / Bulut S3 Kurulumu:** Bu klasördeki `Tweets.csv` dosyasını oluşturduğunuz S3 / DigitalOcean Spaces bucket'ı altındaki `landing-zone/` klasörüne yükleyin (`s3://<bucket_name>/landing-zone/Tweets.csv`).
